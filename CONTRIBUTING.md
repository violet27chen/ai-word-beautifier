# Contributing to AI Word 排版美化助手

Welcome! We're thrilled that you're interested in contributing to the AI Word 排版美化助手 project. Your contributions make this project better and help us create a more powerful tool for everyone.

## Ways to Contribute
There are several ways you can contribute:
- **Bug Reports**: If you find any bugs, please report them in the issues section.
- **Feature Ideas**: We welcome suggestions for new features or improvements.
- **Documentation**: Help us improve our documentation by clarifying existing content or adding new sections.
- **Code**: If you want to dive into the code, feel free to submit enhancements or fixes.

## Setting Up the Project Locally
To run the project locally, follow these general steps:
1. Clone the repository:
   ```bash
   git clone https://github.com/violet27chen/ai-word-beautifier.git
   cd ai-word-beautifier
   ```
2. Install the dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

## Submitting a Pull Request
To submit a pull request, please follow these steps:
1. **Fork the repository** on GitHub.
2. **Create a new branch** for your feature or bug fix:
   ```bash
   git checkout -b my-feature-branch
   ```
3. **Commit your changes**:
   ```bash
   git commit -m "Add some feature"
   ```
4. **Push to your fork**:
   ```bash
   git push origin my-feature-branch
   ```
5. **Open a pull request** on GitHub.

## Code Style
This project is written in TypeScript. Please follow the existing code style and conventions when making contributions to ensure consistency throughout the codebase.
